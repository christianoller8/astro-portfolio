## Context

The client ran a legacy system that made crew scheduling difficult. The project consisted of refactoring and migrating the old interface to a modern, fast and accessible SPA (Single Page Application).

## Solution

We chose **Angular** for its robustness in enterprise applications. I used **RxJS** to handle complex data streams and asynchronous loading states, making sure critical information (flight schedules) was always in sync.

### Achievements

* Load time reduced from 8s to **1.2s**.
* Fully *responsive* interface for use on crew tablets.
* Integration with corporate OAuth2 authentication systems.
