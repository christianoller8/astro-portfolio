## Overview

TaskFlow is a SaaS tool designed to help project managers visualize their teams' performance. The goal was to create a clean, dark ("Dark Mode first") and highly interactive interface where complex data feels simple.

## Technical Implementation

I used **React** together with **TypeScript** to guarantee type safety in a data-rich application. For the visualizations I integrated **D3.js**, building custom charts that respond to user filters in real time.

> "Being able to see bottlenecks in real time changed the way we work." — CTO at StartUp Flow.

## Key Features

1.  **Real-time Updates:** Instant sync through Firebase Firestore.
2.  **Drag & Drop:** Kanban-style task management.
3.  **Automated Reports:** Weekly PDF generation.
